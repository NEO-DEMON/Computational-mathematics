# Лабораторная работа №1 — Численное интегрирование

Интерактивный программный комплекс по дисциплине **«Вычислительная математика»** для расчёта определённых интегралов методами **постоянного** и **переменного (адаптивного)** шага, визуализации геометрической интерпретации квадратурных формул и сравнительного анализа погрешностей.

---

## Цель работы

Изучение и программная реализация классических квадратурных формул Ньютона — Котеса с постоянным шагом, а также алгоритмов автоматического выбора шага (правило Рунге двойного пересчёта и локально-адаптивное интегрирование) для вычисления определённого интеграла:

$$I = \int_{a}^{b} f(x)\,dx$$

и исследование зависимости абсолютной ($\Delta$) и относительной ($\delta$) погрешностей от способа разбиения отрезка интегрирования $[a, b]$.

---

## Реализованный функционал

### 1. Численные методы с постоянным шагом ($h = \frac{b - a}{n}$)
- **Метод левых прямоугольников** — аппроксимация на каждом подотрезке значением в левом узле $f(x_i)$, порядок точности $O(h)$.
- **Метод правых прямоугольников** — аппроксимация значением в правом узле $f(x_{i+1})$, порядок точности $O(h)$.
- **Метод средних прямоугольников** — аппроксимация значением в центральной точке $f\left(x_i + \frac{h}{2}\right)$, порядок точности $O(h^2)$ (на стороне клиента для интерактивного построения и сравнения).
- **Метод трапеций** — линейная интерполяция на каждом шаге, порядок точности $O(h^2)$.
- **Метод парабол (формула Симпсона)** — квадратичная интерполяция по трём узлам (с автоматическим приведением нечётного $n$ к чётному $n + 1$), порядок точности $O(h^4)$.

### 2. Алгоритмы с переменным шагом (по заданной точности $\varepsilon$)
- **Алгоритм двойного пересчёта (правило Рунге)** — последовательное удвоение числа разбиений ($n \to 2n$) на базе формулы левых прямоугольников до выполнения критерия остановки $|I_{2n} - I_n| \le \varepsilon$.
- **Локально-адаптивный алгоритм** — рекурсивное дробление только тех подотрезков $[x_0, x_1]$, на которых локальная оценка погрешности превышает допустимый порог $\varepsilon$, с подсчётом числа принятых элементарных участков (`segments`) и общего числа вызовов функции $f(x)$ (`func_evals`).

### 3. Аналитическое ядро и парсер математических выражений
- Символьное вычисление эталонного значения интеграла $I_{\text{exact}}$ по формуле Ньютона — Лейбница с помощью библиотеки **SymPy**.
- Поддержка естественной математической записи: степени `^` и `**`, неявное умножение (`2x`, `3sin(x)`, `(x+1)(x-1)`), константы `pi`, `e`, тригонометрические и обратные тригонометрические функции (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`), экспонента `exp(x)`, логарифмы `ln(x)` / `log(x)`, корень `sqrt(x)`, модуль `abs(x)`.
- Контроль области определения функции на отрезке $[a, b]$ и обработка особых случаев ($a = b$, $a > b$).

### 4. Визуализация и аналитика (Apple HIG UI)
- **4 сводные карточки KPI:** численный результат $I_{\text{calc}}$, точное значение SymPy $I_{\text{exact}}$, абсолютная погрешность $\Delta = |I_{\text{exact}} - I_{\text{calc}}|$ и относительная погрешность $\delta = \frac{\Delta}{|I_{\text{exact}}|} \cdot 100\%$.
- **Интерактивный SVG-график:** отображение гладкой кривой $y = f(x)$, закрашенных фигур разбиения (прямоугольников, трапеций, парабол Лагранжа или неравномерной адаптивной сетки) и инспектора координат $(x, f(x))$ при наведении курсора.
- **Журнал вычислений:**
  - Пакетное сравнение всех 6 методов одной кнопкой **«Сравнить все методы»**.
  - Автоматическое ранжирование результатов с цветовой индикацией (**«Лучший»**, **«Средний»**, **«Худший»**).
  - Полноэкранный режим анализа со сводной статистикой и **экспорт в CSV (UTF-8 BOM)** для Microsoft Excel / Apple Numbers.
- **Встроенная документация:** подробный справочник по всем формулам, элементам управления, числам и архитектуре прямо внутри интерфейса (кнопка **«Документация»**).
- **Светлая и тёмная темы оформления.**

## Установка и запуск

### Предварительные требования
- **Python** 3.10+
- **Node.js** 18+ и **npm**

### 1. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd numerical-integration-app
```

### 2. Настройка Backend (FastAPI + SymPy)
```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # На Windows: venv\Scripts\activate
pip install -r requirements.txt
cd ..
```

### 3. Настройка Frontend (React + Vite)
```bash
cd frontend
npm install
cd ..
```

### 4. Запуск приложения

#### Вариант А — Одной командой (macOS / Linux)
```bash
sh ./start.sh
```

#### Вариант Б — В двух терминалах
**Терминал 1 (Backend, порт `8001`):**
```bash
cd backend
./venv/bin/python3 -m uvicorn main:app --host 127.0.0.1 --port 8001 --reload
```

**Терминал 2 (Frontend, порт `5173`):**
```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

После запуска откройте в браузере:
- **Веб-интерфейс приложения:** [http://127.0.0.1:5173/](http://127.0.0.1:5173/)
- **Интерактивная документация API (Swagger UI):** [http://127.0.0.1:8001/docs](http://127.0.0.1:8001/docs)

## Эндпоинты REST API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/integrate/const` | Расчёт интеграла выбранным методом с постоянным шагом (`method`: `1` — левые прям., `2` — правые прям., `3` — трапеции, `4` — Симпсон) |
| `POST` | `/api/integrate/variable` | Расчёт интеграла с переменным шагом по точности `eps` (`algo_type`: `1` — двойной пересчёт Рунге, `2` — локально-адаптивный) |
| `POST` | `/api/integrate/compare` | Пакетное вычисление интеграла сразу всеми 6 методами для сравнительного анализа |
