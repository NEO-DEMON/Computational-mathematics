# Численное интегрирование и решение задачи Коши для ОДУ

Интерактивный программный комплекс по дисциплине **«Вычислительная математика»** для:
1. **Численного интегрирования** определённых интегралов методами **постоянного** и **переменного (адаптивного)** шага.
2. **Численного и аналитического решения задачи Коши** для обыкновенных дифференциальных уравнений (ОДУ) **1-го и 2-го порядков**, а также **систем из 3-х ОДУ** методами **Эйлера** и **Рунге — Кутта 4-го порядка**.

---

## Цель работы

1. Изучение и программная реализация классических квадратурных формул Ньютона — Котеса с постоянным шагом и алгоритмов автоматического выбора шага (правило Рунге двойного пересчёта и локально-адаптивное интегрирование) для вычисления определённого интеграла:

$$I = \int_{a}^{b} f(x)\,dx$$

2. Изучение и программная реализация одношаговых численных методов решения задачи Коши для ОДУ 1-го порядка $y' = f(x, y)$, ОДУ 2-го порядка $y'' = f(x, y, y')$ и нормальных систем из 3-х ОДУ первого порядка на отрезке $[x_0, b]$ с исследованием сходимости, апостериорной оценки Рунге на сетках $h$ и $h/2$ и автоматическим подбором шага метода Эйлера (п. 3.4 методички).

---

## Реализованный функционал

### Модуль 1 — Численное интегрирование (`∫ Интегралы`)

#### 1.1. Численные методы с постоянным шагом ($h = \frac{b - a}{n}$)
- **Метод левых прямоугольников** — аппроксимация на каждом подотрезке значением в левом узле $f(x_i)$, порядок точности $O(h)$.
- **Метод правых прямоугольников** — аппроксимация значением в правом узле $f(x_{i+1})$, порядок точности $O(h)$.
- **Метод средних прямоугольников** — аппроксимация значением в центральной точке $f\left(x_i + \frac{h}{2}\right)$, порядок точности $O(h^2)$ (реализован в `math_engine.py` и доступен через `/api/integrate/const` при `method=5`).
- **Метод трапеций** — линейная интерполяция на каждом шаге, порядок точности $O(h^2)$.
- **Метод парабол (формула Симпсона)** — квадратичная интерполяция по трём узлам (с автоматическим приведением нечётного $n$ к чётному $n + 1$), порядок точности $O(h^4)$.

#### 1.2. Алгоритмы с переменным шагом (по заданной точности $\varepsilon$)
- **Алгоритм двойного пересчёта (правило Рунге)** — последовательное удвоение числа разбиений ($n \to 2n$) на базе формулы левых прямоугольников до выполнения критерия остановки $|I_{2n} - I_n| \le \varepsilon$.
- **Локально-адаптивный алгоритм** — рекурсивное дробление подотрезков $[x_0, x_1]$ с пропорциональным масштабированием локального допуска $\varepsilon_{\text{лок}} = \varepsilon \cdot \frac{h}{b - a}$, подсчётом числа принятых элементарных участков (`segments`) и общего числа вызовов функции $f(x)$ (`func_evals`).

### Модуль 2 — Задача Коши для ОДУ (`y' ОДУ`)

- **Три класса дифференциальных задач:**
  - **ОДУ 1-го порядка:** $y' = f(x, y),\; y(x_0) = y_0$ на отрезке $[x_0, b]$.
  - **ОДУ 2-го порядка:** $y'' = f(x, y, z)$, где $z = y'$, с начальными условиями $y(x_0) = y_0,\; y'(x_0) = z_0$ (сведение к нормальной системе 2-х уравнений).
  - **Система 3-х ОДУ:** $\frac{dx}{dt} = f_1(t, x, y, z),\; \frac{dy}{dt} = f_2(t, x, y, z),\; \frac{dz}{dt} = f_3(t, x, y, z)$ на $[t_0, b]$.
- **Численные методы:**
  - **Явный метод Эйлера** — порядок точности $O(h)$, правило Рунге с делителем $2^1 - 1 = 1$.
  - **Классический метод Рунге — Кутта 4-го порядка (РК4)** — порядок точности $O(h^4)$, правило Рунге с делителем $2^4 - 1 = 15$.
- **Аналитический эталон и контроль точности:**
  - Автоматический поиск точного аналитического решения задачи Коши через `sympy.dsolve` с подстановкой начального условия $y(x_0) = y_0$ (при отсутствии замкнутой элементарной формы — эталонная сетка РК4 повышенной точности).
  - Одновременный расчёт на основной ($h$) и половинной ($h/2$) сетках для вычисления апостериорной погрешности Рунге в каждом узле.
  - Автоматический подбор шага метода Эйлера для достижения точности метода Рунге — Кутта (**п. 3.4 методички**).
  - 10 встроенных контрольных примеров из методички и лекционного конспекта.

### Аналитическое ядро и парсер математических выражений
- Единый нормализатор выражений и символьное ядро **SymPy** (`backend/parser.py`).
- Поддержка естественной математической записи: степени `^` и `**`, неявное умножение (`2x`, `3sin(x)`, `(x+1)(x-1)`), научная нотация (`1e-3`), константы `pi`, `e`, тригонометрические, обратные тригонометрические и гиперболические функции (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh`), экспонента `exp(x)`, логарифмы `ln(x)` / `log(x)` / `log10(x)`, корни `sqrt(x)` / `cbrt(x)`, модуль `abs(x)`.
- Контроль области определения функции и обработка особых случаев ($a = b$, $a > b$).

### Визуализация и аналитика (Apple HIG UI)
- **Сводные карточки KPI:** 4 карточки ключевых метрик в обоих режимах (численное значение, эталон SymPy / РК4, погрешности $\Delta$, $\delta$, шаг сетки $h$).
- **Интерактивные SVG-графики:** геометрическая интерпретация квадратурных формул и графики интегральных кривых (Эталон, Эйлер, РК4) с переключением компонент `x(t) / y(t) / z(t)` и двусторонней синхронизацией узлов с таблицей.
- **Таблицы узлов и журналы вычислений:**
  - Автоматическое ранжирование результатов внутри каждой задачи с цветовой индикацией (**«Лучший»**, **«Средний»**, **«Худший»**) и постоянной сводной полосой **«Лучший результат»**.
  - Полноэкранный режим (`На весь экран`) для детального анализа всех таблиц и **экспорт в CSV (UTF-8 BOM)** для Microsoft Excel / Apple Numbers.
- **Двухрежимная встроенная документация:** подробный 7-раздельный справочник отдельно для режимов **«∫ Интегралы»** и **«y' ОДУ»** (кнопка **«Документация»**).
- **Светлая и тёмная темы оформления.**

## Установка и запуск

### Предварительные требования
- **Python** 3.10+
- **Node.js** 18+ и **npm**

### 1. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd numerical-integration-app
```

### 2. Настройка Backend (FastAPI + SymPy)
```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # На Windows: venv\Scripts\activate
pip install -r requirements.txt
cd ..
```

### 3. Настройка Frontend (React + Vite)
```bash
cd frontend
npm install
cd ..
```

### 4. Запуск приложения

#### Вариант А — Одной командой (macOS / Linux)
```bash
sh ./start.sh
```

#### Вариант Б — В двух терминалах
**Терминал 1 (Backend, порт `8001`):**
```bash
cd backend
./venv/bin/python3 -m uvicorn main:app --host 127.0.0.1 --port 8001 --reload
```

**Терминал 2 (Frontend, порт `5173`):**
```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

После запуска откройте в браузере:
- **Веб-интерфейс приложения:** [http://127.0.0.1:5173/](http://127.0.0.1:5173/)
- **Интерактивная документация API (Swagger UI):** [http://127.0.0.1:8001/docs](http://127.0.0.1:8001/docs)

## Эндпоинты REST API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/integrate/const` | Расчёт интеграла выбранным методом с постоянным шагом (`method`: `1` — левые прям., `2` — правые прям., `3` — трапеции, `4` — Симпсон, `5` — средние прям.) |
| `POST` | `/api/integrate/variable` | Расчёт интеграла с переменным шагом по точности `eps` (`algo_type`: `1` — двойной пересчёт Рунге, `2` — локально-адаптивный) |
| `POST` | `/api/integrate/compare` | Пакетное вычисление интеграла сразу всеми 6 методами для сравнительного анализа |
| `POST` | `/api/ode/first` | Решение задачи Коши для ОДУ 1-го порядка $y' = f(x, y)$ методами Эйлера и РК4 (с сетками $h$, $h/2$ и аналитическим решением SymPy) |
| `POST` | `/api/ode/first/match` | Автоматический подбор шага $h$ (числа разбиений $n$) метода Эйлера для достижения точности РК4 (п. 3.4) |
| `POST` | `/api/ode/second` | Решение задачи Коши для ОДУ 2-го порядка $y'' = f(x, y, z)$ сведением к системе 2-х уравнений |
| `POST` | `/api/ode/system` | Решение задачи Коши для нормальной системы 3-х ОДУ первого порядка |
