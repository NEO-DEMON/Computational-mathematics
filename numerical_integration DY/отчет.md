## 2. Теоретические сведения и расчётные формулы.

Требуется найти приближённое решение начальной задачи (задачи Коши) для обыкновенного дифференциального уравнения первого порядка на отрезке $[x_0, b]$ при заданном начальном условии:

$$y' = f(x, y), \quad y(x_0) = y_0, \quad x \in [x_0, b]$$

Отрезок интегрирования $[x_0, b]$ разбивается на $n$ равных частей с постоянным шагом $h$ и равномерной сеткой узлов:

$$h = \frac{b - x_0}{n}, \quad x_i = x_0 + i \cdot h, \quad i = 0, 1, \dots, n$$

### 2.1. Численные методы для ОДУ 1-го порядка.

**Явный метод Эйлера (порядок точности $O(h)$).** Интегральная кривая на каждом элементарном шаге $[x_i, x_{i+1}]$ заменяется отрезком касательной, наклон которой вычисляется в левом узле $(x_i, y_i)$:

$$y_{i+1} = y_i + h \cdot f(x_i, y_i), \quad i = 0, 1, \dots, n - 1$$

**Метод Рунге — Кутта 4-го порядка (порядок точности $O(h^4)$).** На каждом шаге вычисляются четыре промежуточных наклона $k_1, k_2, k_3, k_4$ (в начале, в середине и в конце шага), которые усредняются с весами формулы Симпсона $(1 : 2 : 2 : 1) / 6$:

$$k_1 = h \cdot f(x_i, y_i)$$

$$k_2 = h \cdot f\!\left(x_i + \frac{h}{2},\; y_i + \frac{k_1}{2}\right)$$

$$k_3 = h \cdot f\!\left(x_i + \frac{h}{2},\; y_i + \frac{k_2}{2}\right)$$

$$k_4 = h \cdot f(x_i + h,\; y_i + k_3)$$

$$y_{i+1} = y_i + \frac{k_1 + 2k_2 + 2k_3 + k_4}{6}$$

### 2.2. Решение ОДУ 2-го порядка и нормальных систем 3-х ОДУ.

**Сведение ОДУ 2-го порядка к системе двух уравнений 1-го порядка.** Задача Коши для уравнения второго порядка $y'' = f(x, y, y')$ с начальными условиями $y(x_0) = y_0,\; y'(x_0) = z_0$ путём введения новой неизвестной функции $z(x) = y'(x)$ приводится к нормальной системе двух уравнений первого порядка:

$$\begin{cases} y' = z, & y(x_0) = y_0 \\ z' = f(x, y, z), & z(x_0) = z_0 \end{cases}$$

Для метода Эйлера пересчёт в узле $x_i$ выполняется по формулам:

$$y_{i+1} = y_i + h \cdot z_i, \quad z_{i+1} = z_i + h \cdot f(x_i, y_i, z_i)$$

Для метода Рунге — Кутта 4-го порядка на каждом шаге синхронно вычисляются четыре пары коэффициентов $(k_1, l_1), (k_2, l_2), (k_3, l_3), (k_4, l_4)$ для приращений функции $y$ и её производной $z$.

**Нормальная система трёх ОДУ 1-го порядка.** Для системы относительно независимой переменной $t \in [t_0, b]$:

$$\begin{cases} \dfrac{dx}{dt} = f_1(t, x, y, z), & x(t_0) = x_0 \\[6pt] \dfrac{dy}{dt} = f_2(t, x, y, z), & y(t_0) = y_0 \\[6pt] \dfrac{dz}{dt} = f_3(t, x, y, z), & z(t_0) = z_0 \end{cases}$$

все три компоненты фазового вектора $(x_i, y_i, z_i)$ вычисляются одновременно на каждом шаге $t_{i+1} = t_i + h$.

### 2.3. Оценка погрешности вычислений и подбор шага (п. 3.4).

**Точное решение и абсолютная погрешность.** Аналитическое решение задачи Коши $y_{\text{точн}}(x)$ находится символьным решателем `sympy.dsolve` (при отсутствии решения в элементарных функциях в качестве эталона используется расчёт методом Рунге — Кутта 4-го порядка на сгущённой сетке). Максимальная абсолютная погрешность на сетке узлов определяется по формуле:

$$\Delta = \max_{0 \le i \le n} \left| y_{\text{точн}}(x_i) - y_i \right|$$

**Апостериорная оценка по правилу Рунге.** Одновременно с расчётом на основной сетке с шагом $h$ ($n$ разбиений) выполняется расчёт с половинным шагом $h/2$ ($2n$ разбиений), после чего в каждом узле $x_i$ вычисляется оценка погрешности:

$$R_i = \frac{\left| y_i^{(h)} - y_{2i}^{(h/2)} \right|}{2^p - 1}$$

где порядок метода $p = 1$ для метода Эйлера ($2^1 - 1 = 1$) и $p = 4$ для метода Рунге — Кутта ($2^4 - 1 = 15$).

**Алгоритм подбора шага метода Эйлера (п. 3.4).** Для достижения методом Эйлера точности, сопоставимой с методом Рунге — Кутта при $n = 10$, число разбиений последовательно удваивается ($n = 10 \cdot 2^k$), пока максимальное расхождение между решениями в контрольных узлах не станет меньше заданного порога $\varepsilon = 0.001$:

$$\max_{0 \le i \le 10} \left| y_{\text{Эйлер}}(x_i) - y_{\text{РК4}}(x_i) \right| \le \varepsilon$$

## 4. Листинг основного кода программы (Python).

Серверная часть решения задач Коши разделена на три логических блока. Ниже приведено описание работы каждого блока и ключевые фрагменты кода без служебных обёрток.

### 4.1. Компиляция правой части ОДУ и символьное решение задачи Коши (`backend/ode_engine.py`)

Модуль принимает строковую запись правой части уравнения, нормализует синтаксис через единый парсер `normalize_math_expression`, компилирует быструю функцию вычисления через `sympy.lambdify` и находит точное аналитическое решение задачи Коши $y' = f(x, y),\; y(x_0) = y_0$ с помощью `sympy.dsolve`:

```python
def compile_ode_function(expr_str: str, allowed_vars: tuple):
    normalized = _normalize_ode_expression(expr_str)
    sym_vars = {v: sp.Symbol(v, real=True) for v in allowed_vars}
    expr = sp.sympify(normalized, locals=build_sympy_locals(sym_vars))

    ordered_syms = [sym_vars[v] for v in allowed_vars]
    f_callable = sp.lambdify(ordered_syms, expr, modules=["math"])
    return f_callable, expr, sym_vars


def try_symbolic_exact_ode1(expr, sym_vars, x0: float, y0: float):
    x_sym, y_sym = sym_vars["x"], sym_vars["y"]
    y_func = sp.Function("y")(x_sym)
    ode_eq = sp.Eq(sp.Derivative(y_func, x_sym), expr.subs(y_sym, y_func))

    # Аналитическое решение задачи Коши с начальным условием y(x0) = y0
    sol = sp.dsolve(ode_eq, y_func, ics={y_func.subs(x_sym, x0): y0})
    rhs = sp.simplify(sol.rhs)
    exact_callable = sp.lambdify(x_sym, rhs, modules=["math"])
    return exact_callable, str(rhs).replace("**", "^")
```

### 4.2. Численные методы Эйлера и Рунге — Кутта 4-го порядка (`backend/ode_engine.py`)

Реализация явного метода Эйлера $O(h)$, классического метода Рунге — Кутта 4-го порядка $O(h^4)$ и алгоритма автоматического подбора числа разбиений $n$ для метода Эйлера по п. 3.4 методички:

```python
def euler_ode1(f, x0: float, y0: float, b: float, n: int):
    h = (b - x0) / n
    xs = [x0 + i * h for i in range(n + 1)]
    ys = [0.0] * (n + 1)
    ys[0] = float(y0)
    for i in range(n):
        ys[i + 1] = ys[i] + h * f(xs[i], ys[i])
    return xs, ys, h


def rk4_ode1(f, x0: float, y0: float, b: float, n: int):
    h = (b - x0) / n
    xs = [x0 + i * h for i in range(n + 1)]
    ys = [0.0] * (n + 1)
    ys[0] = float(y0)
    for i in range(n):
        xi, yi = xs[i], ys[i]
        k1 = h * f(xi, yi)
        k2 = h * f(xi + 0.5 * h, yi + 0.5 * k1)
        k3 = h * f(xi + 0.5 * h, yi + 0.5 * k2)
        k4 = h * f(xi + h, yi + k3)
        ys[i + 1] = yi + (k1 + 2.0 * k2 + 2.0 * k3 + k4) / 6.0
    return xs, ys, h


def match_euler_to_rk4_ode1(func_str: str, x0: float, y0: float, b: float, n_rk4=10, target_diff=0.001):
    f, _, _ = compile_ode_function(func_str, ("x", "y"))
    _, ys_rk, _ = rk4_ode1(f, x0, y0, b, n_rk4)
    mult = 1
    while n_rk4 * mult <= 50000:
        cur_n = n_rk4 * mult
        _, ys_eu, _ = euler_ode1(f, x0, y0, b, cur_n)
        if max(abs(ys_eu[i * mult] - ys_rk[i]) for i in range(n_rk4 + 1)) <= target_diff:
            break
        mult *= 2
    return solve_ode1(func_str, x0, y0, b, cur_n, method="euler")
```

Реализация сведения ОДУ 2-го порядка ($y' = z,\; z' = f(x, y, z)$) и векторного решения системы трёх ОДУ 1-го порядка методом Рунге — Кутта 4-го порядка:

```python
def rk4_ode2(f, x0: float, y0: float, z0: float, b: float, n: int):
    h = (b - x0) / n
    xs = [x0 + i * h for i in range(n + 1)]
    ys, zs = [float(y0)] + [0.0] * n, [float(z0)] + [0.0] * n
    for i in range(n):
        xi, yi, zi = xs[i], ys[i], zs[i]
        k1, l1 = h * zi, h * f(xi, yi, zi)
        k2, l2 = h * (zi + 0.5 * l1), h * f(xi + 0.5 * h, yi + 0.5 * k1, zi + 0.5 * l1)
        k3, l3 = h * (zi + 0.5 * l2), h * f(xi + 0.5 * h, yi + 0.5 * k2, zi + 0.5 * l2)
        k4, l4 = h * (zi + l3), h * f(xi + h, yi + k3, zi + l3)
        ys[i + 1] = yi + (k1 + 2.0 * k2 + 2.0 * k3 + k4) / 6.0
        zs[i + 1] = zi + (l1 + 2.0 * l2 + 2.0 * l3 + l4) / 6.0
    return xs, ys, zs, h
```

Экспериментально подтверждены теоретические порядки точности исследованных одношаговых схем на одинаковой сетке $n = 10$:
1. На контрольном примере №1 ($y' = y(1 - x)$, $x \in [0; 1]$) явный метод Эйлера 1-го порядка точности $O(h)$ даёт максимальную погрешность $\Delta = 5.31 \cdot 10^{-2}$, в то время как метод Рунге — Кутта 4-го порядка $O(h^4)$ при том же шаге $h = 0.1$ обеспечивает погрешность $\Delta = 2.64 \cdot 10^{-7}$ (выигрыш по точности более чем в $2 \cdot 10^5$ раз).
2. Исследование сходимости по п. 3.4 методички показало, что для приближения решения методом Эйлера к решению методом Рунге — Кутта ($n = 10$) с точностью до $10^{-3}$ шаг метода Эйлера в КП №1 необходимо уменьшить в 64 раза ($n = 640,\; h = 0.0015625$, при этом расхождение составило $8.58 \cdot 10^{-4}$).
3. При решении задачи Коши для системы трёх дифференциальных уравнений (КП №3) уменьшение шага метода Эйлера в 10 раз (с $h = 0.03,\; n = 10$ до $h = 0.003,\; n = 100$) привело к пропорциональному снижению максимальной погрешности ровно в 10 раз (с $9.91 \cdot 10^{-3}$ до $9.93 \cdot 10^{-4}$), что полностью подтверждает первый порядок точности $O(h)$ схемы Эйлера.
